# DukaBook - Duka Management App (Kenya)

Simple offline app for duka owners to track sales, debts (deni), and stock.

Built for Kenyan shops — works without internet, just like M-Pesa.

## Features
- ✅ Sell in 5 seconds
- ✅ Track debts - who owes you
- ✅ Low stock alerts (Bread 5 left)
- ✅ Works offline - SQLite
- ✅ Daily sales: KES 4,300

## Tech
Flutter + SQLite (offline first) + Supabase (optional backup)

## Build APK
flutter pub get
flutter build apk --release

APK at: build/app/outputs/flutter-apk/app-release.apk
